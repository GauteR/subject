# Subject

Automatically fills the **mail subject** for **World of Warcraft: Forever**.

## Features

- Attach an item and the subject becomes the first item's name (stacks add `x20`)
- Send money without an item and the subject becomes the amount, e.g. `Money: 12g 5s 3c`
- Never overwrites a subject you typed yourself
- Each behaviour can be switched off in `Config.lua`

## Install

Install via CurseForge, or copy the `subject` folder to `_forever_/Interface/AddOns/`, then `/reload`.
